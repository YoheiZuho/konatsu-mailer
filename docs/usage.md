# 使い方ガイド

konatsu の画面構成と操作方法です。

## 画面構成（三ペイン）

デフォルトは「リーディングペイン」レイアウト（設計案 B）です。

```
┌─────────────────────────────────────────────────────────┐
│ TopBar:  ☰  ロゴ   [ 検索 ]      同期バッジ ☀/🌙 ⚙ ⏻       │
├──────────┬───────────────────┬────────────────────────────┤
│ Sidebar  │  メール一覧        │  本文（リーディングペイン） │
│  作成    │  [すべて][未読]    │  件名・ラベル・スター       │
│  受信箱  │  ┌──────────────┐  │  ┌──────────────────────┐  │
│  スター  │  │ ● 送信者  時刻│  │  │ ✨ AI 要約・重要度    │  │
│  重要    │  │   件名        │  │  └──────────────────────┘  │
│  送信済  │  │   AI要約 ラベル│  │  本文（スレッド表示）      │
│  …      │  └──────────────┘  │  ┌──────────────────────┐  │
│  ラベル  │   …（仮想スクロール）│  │ ↩ AIで返信案    送信 ▶│  │
└──────────┴───────────────────┴────────────────────────────┘
```

> 画面幅が狭い場合（モバイル / 1024px 未満）は単一カラムになり、一覧 → 本文へ遷移します。

## TopBar

- **☰** サイドバーの開閉
- **検索** 件名・送信者・本文プレビューを全文検索（tsvector）＋部分一致（日本語対応）。入力は自動で反映
- **同期バッジ** サーバーとの接続状態（`同期中` / `再接続中` / `切断`）をリアルタイム表示
- **☀/🌙** テーマのクイック切替
- **⚙** 設定ダイアログ
- **⏻** ログアウト

## サイドバー

- **作成** 新規メール作成ダイアログを開く
- **フォルダ** 接続中アカウントの **実際の IMAP フォルダ** を表示します（受信トレイ・送信済み・下書き・迷惑メール(Junk)・ゴミ箱・アーカイブ等は IMAP の特殊用途フラグから自動判別）。「スター付き」「重要」はフォルダ横断の仮想ビューです。
- **ラベル** ユーザー定義および AI 自動付与のラベル。クリックで絞り込み
- 一覧（案A）と本文プレビュー（案B）の境界、サイドバー幅は**ドラッグで調整**できます。

### ドラッグ＆ドロップ

メール行をつかんで以下にドロップすると振り分けできます。

- **サイドバーのフォルダ**（受信トレイ・送信済み・ゴミ箱など）へ → IMAP でそのフォルダへ移動
- **サイドバーのラベル**へ → そのラベルを付与
- **受信トレイ上部のカテゴリタブ**（メイン/プロモーション/ソーシャル/ニュースレター）へ → カテゴリを変更

## メール一覧

- 仮想スクロールで高速描画。下までスクロールすると次ページを自動取得します。
- **フィルタ**: 「すべて」「未読」「重要」
- 各行: 送信者・時刻・件名・AI 要約（または本文プレビュー）・ラベル・添付/未読インジケータ
- **★** クリックでスター付け（即時反映＝楽観的更新）
- 行をクリックすると本文を表示し、自動的に既読になります。

## 本文（リーディングペイン）

- 件名・ラベル・スター・操作ツールバー（未読に戻す、AI 再解析 ✨ など）
- **AI 要約カード** — LLM による 1 行要約と重要度バッジ（重要度 高/緊急 は強調色）
- **スレッド表示** — 過去メッセージは折り畳み、最新を展開
- **HTML メール** — DOMPurify でサニタイズ。外部画像はプライバシー保護のため既定でブロックし、「画像を表示」で読み込みます。

### 翻訳

LibreTranslate を設定している場合（[configuration.md](configuration.md) の `LIBRETRANSLATE_URL`）、各メッセージのヘッダに **翻訳** アイコンが表示されます。

- クリックすると本文が指定言語に翻訳され、原文との切り替え（「原文を表示」）ができます。
- 翻訳先の言語は設定 →「外観」→「翻訳先の言語」で変更できます（既定は日本語）。
- HTML メールはプレーンテキストを抽出して翻訳します。翻訳エンジンは OSS の [LibreTranslate](https://libretranslate.com/) で、自己ホストすればメール本文を外部に送らず翻訳できます。

### 返信（クイックリプライ）

- 本文下部の入力欄から返信できます。
- **AI で返信案** — スレッド内容をもとに LLM が返信文を生成し、入力欄にストリーミング表示します。生成中にもう一度押すと停止します。
- **↗** で全画面の作成ダイアログに引き継げます。

## メール作成

「作成」または返信の全画面化で開きます。

- 宛先 / Cc / Bcc（カンマ・セミコロン区切りで複数指定可）、件名、本文
- **AI で下書きを生成** — 件名や入力中の文面を文脈に下書きを生成
- 送信は SMTP 経由（スレッド返信時は `In-Reply-To` / `References` を自動付与）

## 設定（⚙）

| タブ | 内容 |
| :-- | :-- |
| **外観** | テーマ（システム/ライト/ダーク）、キーカラー（プリセット 8 色＋カスタム）、表示密度（ゆったり/コンパクト）、AI 要約の表示、**AI 解析を行わないメール種別**（プロモーション/ソーシャル通知/ニュースレター/自動送信：チェックで要約対象外） |
| **アカウント** | IMAP/SMTP メールアカウントの追加・削除 |
| **AI 接続** | LLM エンドポイントの登録・接続テスト・既定設定 → [llm-setup.md](llm-setup.md) |
| **フィルター** | 受信メールの自動分類ルール（条件→動作）。フォルダ移動・ラベル付与・既読化・スター・カテゴリ設定。 |
| **ラベル** | ラベルの作成・色設定・削除 |
| **通知** | Web Push の有効化／通知するラベルの選択 |

### 受信トレイのカテゴリタブ

受信トレイには **メイン / プロモーション / ソーシャル / ニュースレター** のタブが表示されます。新着メールはヘッダ（メーリングリスト・配信停止・送信元など）から自動分類されます。フィルターの「カテゴリを設定」動作で手動の振り分けルールも作れます。

### 外観のポイント

- キーカラーを変更すると、作成ボタン・選択行・同期バッジ・AI 要約カードなどへ即座に反映されます。文字色（明/暗）は背景輝度から自動判定されます。
- テーマ・キーカラー等の設定はブラウザに保存され、さらにサーバーにも同期されるため、別デバイスでログインしても引き継がれます。

## 通知（Web Push）

1. 設定 → 「通知」→「通知を有効にする」を押し、ブラウザの許可を与えます。
2. 重要度が閾値（既定 4）以上のメールが届くと、AI 要約を本文にしたプッシュ通知が表示されます。
3. 通知をクリックすると該当メールが開きます。

> サーバー側に VAPID 鍵が設定され（[getting-started.md](getting-started.md)）、かつ **AI接続（LLM）が設定済み**である必要があります。通知は新着メールを LLM が解析し、重要度が `NOTIFY_THRESHOLD`（既定 4）以上と判定したときに送信されます。設定→「通知」で対象ラベルを選ぶと、そのラベルが付いたメールだけに絞れます。

## PWA としてインストール

対応ブラウザでは、アドレスバーの「インストール」アイコン、またはメニューから「アプリをインストール」を選ぶと、デスクトップ/ホーム画面のアプリとして起動できます。オフライン時もアプリシェルは即座に起動します。
